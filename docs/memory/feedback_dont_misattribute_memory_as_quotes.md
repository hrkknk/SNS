過去のセッションでAIが引き継ぎ資料や会話から要約・言語化した一文が、そのまま「本人の原則」としてメモリに残ることがある。それを後のセッションで「あなたが置いていた原則」として本人に引用したところ、本人は「そんなこと言ってない」と訂正した（2026-08-03、[[project-sns-phase-status]]の「最優先KPIはシステムの完成度ではなく〜」の一文）。

**Why**: メモリは玉石混淆で、本人の発言そのものと、AIによる要約・推論が区別なく保存されていることがある。後者を前者として扱うと、本人の意図を歪めた前提で議論を進めてしまう。

**How to apply**: メモリの内容を根拠に主張・提案する際、それが本人の言葉そのものなのか、過去のAIの解釈・要約なのか怪しい場合は、「あなたが言った」と断定せず、「以前こう記録されていた」程度の言い方に留める。本人から訂正が入ったら、該当メモリを実態に合わせて即座に修正する。
