コーヒー事業→世界観発信への転換（[[project-coffee-worldview-pivot]]）を検討中、まだ発信の中心テーマや自己開示の度合いといった構想レベルの論点が固まっていないうちに、ポッドキャストの文字起こし方法やAPI料金比較といった戦術・実装寄りの話に流れ込んでしまい、本人から「まだ実装に入る段階じゃない、もっと構想をきちんと考えるべき」と指摘された（2026-08-03）。

**Why**: 技術的に検討しやすい/答えを出しやすいトピック（ツール比較、コスト試算）は具体的で扱いやすいため、つい深掘りしたくなる。しかし土台となる構想（テーマ設定、宗教の開示度、説教臭さの回避、実名/匿名、読者への価値、コーヒー事業との接続タイミングなど、資料内「12. Claudeと次に検討したいこと」に列挙されている論点）が未確定のまま戦術を詰めても、後で前提がひっくり返るリスクが高い。

**How to apply**: この発信プロジェクトの相談では、構想レベルの論点が本人の中で一定固まるまで、ツール選定・コスト計算・実装スクリプトの話には自分から踏み込まない。技術的に面白そうでも、本人が明示的に「実装/戦術を詰めたい」と言うまでは、構想の壁打ち相手に徹する。
