2026-08-03、アップロードされた引き継ぎ資料（coffee_business_rethink_context.md）により判明。[project_sns_phase_status.md](project_sns_phase_status.md) の自己発信プロジェクトは、単独の施策ではなく、この事業再考の一部として始まっている。

**経緯**
- 元々の構想: 自宅焙煎→EC販売→SNSで認知→ブランド育成→将来的に実店舗の喫茶店
- CTO（本人の相談相手、社内外不明だが継続的に助言をもらっている人物）から「デザインや戦略は付け焼き刃。本質・根っこで勝負しないと勝てない」「本当にコーヒーが人生の中心なら研究し尽くしているはず。実際はそうではない」と指摘され、事業の前提を見直した。

**本人の核**
- 最も根源的なのはキリスト教信仰（何を措いても最優先という自覚がある）
- ただし日本社会でキリスト教を前面に出すことに強い社会的リスクを感じており、これまで信仰を表に出さず生きてきた
- 喫茶店をやりたい理由も「コーヒーが好き」ではなく、「かつて教会が担っていた社会的役割（誰でも入れる/一人でいられる/静か/評価されない/自分と向き合える/緩やかなつながりがある/誠実な飲食物がある）を、宗教施設ではない現代的な場として再現したい」というのが本音

**現在の仮説（事業の順序の逆転）**
- 旧: コーヒーEC → ブランド認知 → 顧客 → 喫茶店
- 新: 自分の思想・世界観を発信 → 共感者が生まれる → 小さなコミュニティ形成 → その思想を具体化したプロダクトとしてコーヒー → 最終的に思想を空間化した喫茶店

**自己開示の方針（2026-08-03、本人が決断済み。この論点は決着している）**
- **自己開示はちゃんとやる。プロテスタントであることは隠さず、アイデンティティとして開示する。**
- ただしそれは「自分という人間の属性を隠さない」という意味であって、押し付けがましく伝道することではないし、SNSの全てを信仰の話にすることでもない。
- 以前の「様子を見ながら開示度を決める」段階は終了。今後この点を蒸し返して本人に問い直さない。

**発信の話題は「雑食」が前提（2026-08-03、本人が明言。狭めようとしないこと）**
- 宗教・思想・哲学の話"だけ"をするアカウントではない。コーヒー、喫茶店、音楽、キャンプ、将棋、ギター、エフェクター、映画、アニメ、シーシャ、小説、時事ネタなど、本人の興味の対象すべてを盛り込む。
- 本人の考え: それら全てが自分という人間を構成しており、全てが宗教・哲学・思想と関連しうる。話題が多いことのデメリットはほぼない。音楽に興味があってキャンプに興味がない読者は音楽の記事だけ読めばよく、読者が自己選択する。
- **AIが犯した誤り**: 資料9節のテーマ例の前半（孤独、静けさ、誠実さ等の抽象テーマ）だけを拾い、末尾の「日常生活、猫、音楽、映画、コーヒーなど」を読み落として「狭い思想アカウント」と誤解した。その前提で「テーマがずれているのでコーヒーは売れない」「到達は数千人が天井」「話題が雑多だと何者か分からない」と誤った助言をし、いずれも本人に否定された。今後この前提で議論を組み立てない。
- 時事ネタのラベリングリスクは本人も注意点として同意しているが、「あまり臆病になっても仕方ない」というスタンス。過度に慎重な助言をしない。

**発信方針の制約（重要）**
- 「キリスト教アカウント」にはしない。信仰を隠しも偽りもしないが、布教目的にはしない
- 信仰由来の世界観から、誠実に生きるとは/仕事とは/AI時代の人間の価値/孤独/居場所/静けさ/消費社会との距離、といった普遍的テーマを語る
- 目指すのは「宗教の有無に関係なく、この人の世界の見方に興味がある」と思われること
- ブランド美意識（Quiet/Honest/Practical、BOSS/Fender、ミッドセンチュリー、Radiohead的内省性）は核ではなく、信仰→価値観→美意識→デザイン→商品、という上位から生まれる表層と位置づけ直した
- SNS運用は自動化してよいが、発信内容そのものをAIに丸投げしない。AIは編集・構成・媒体変換・投稿管理の道具

**Why**: これを知らずに発信のテーマ設計やトーン、コーヒー事業とのタイミングを助言すると、本人が最も避けたい「説教臭い思想アカウント」や「浅いブランディング」に逆戻りするリスクがある。
**How to apply**: 今後、発信テーマ・コンテンツカテゴリ・コーヒー事業とのタイミング・キリスト教の開示度合いを検討する際は、必ずこの「上位（信仰・世界観）から下位（商品）」という順序と、「布教ではなく普遍的テーマへの翻訳」という制約を前提にする。本人はこの仮説自体もまだ確定ではないと明言しており、安易に全肯定せず、事業性・発信戦略・本人の適性の観点から厳しく検証してほしいと依頼している。
