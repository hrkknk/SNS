本人は7年前からSpotify for Createrでポッドキャストを配信している。タイトルは「お前ら全員罪人わろた」、キリスト教に関するゆるい雑談番組。大学の友人と共同でやっており、これまで明確な目的なく続けてきた。[[project-coffee-worldview-pivot]] の文脈で、この番組を発信戦略にどう組み込むかを検討中。

**本人が相談したい論点は2つある（2026-08-03）**
1. 宗教性を隠さないと決めた以上、ポッドキャストの蓄積を活用しないのは勿体ない → 以下の「位置づけの結論」「note記事化」で検討済み
2. **ポッドキャスト自体のフォロワーをもっと獲得したい** → 未検討。これは番組を事業の道具にする話（＝避けたい私物化）ではなく、番組自体のための目標であり、友人とも共有できる性質のもの。「番組に目的を持たせない」という結論とは矛盾しない。

**位置づけの結論（2026-08-03、本人合意済み）**
- **番組そのものは今まで通り、目的を持たせずに続ける。変えるのは番組の外側（本人が自分の発信の中でどう言及するか）だけ。** 目的を持たせた瞬間に、この番組が持っていた性質（何の役にも立たなくていい、ただの雑談）が変質してしまう。本人が「私物化は避けたい」と言ったとき直感的に守ろうとしていたのはここ。
- ポッドキャストは、ギター・シーシャ・将棋などと並ぶ「本人を構成する要素の一つ」として普通に言及してよい。隠さないし、段階的に見せる必要もない。
- **最大の価値は記事の材料であること以上に、「7年361本続けている」という事実そのもの**。大半の人が3ヶ月でやめるものを7年続けており、しかも自己申告ではなく公開された配信履歴という検証可能な形で残っている。「口だけではない」ことの証拠として強い。
- **廃案となった旧整理**: 当初は「表の発信の奥にある"奥の間"」（普遍テーマで引きつけ、踏み込みたい人の受け皿として番組へ誘導）と整理したが、これは自己開示の度合いが未定という前提に立ったものだった。本人が「プロテスタントであることを開示する」「話題は雑食でいく」と決めた時点でこの慎重な構えは不要になった。今後この枠組みで考えない。

**アーカイブについて**: 7年分の音声はSpotify for Createrに全て残っている（消失・散逸はしていない）。ただしテーマ別に検索できる状態ではないため、note/Xの記事と重なるテーマのエピソードに直接リンクするには、エピソード×テーマの軽いインデックス作りが必要（既存のNotion発信基盤を拡張する形で対応できる）。

**事業への流入について（2026-08-03に本人が明確化。以前の記述は誤りだったので訂正済み）**
- 制約は「事業と接続しないこと」ではなく、**「露骨に誘導しないこと」の一点だけ**。番組概要欄や説明に本人の事業へのリンクを貼る程度は、まったく問題ない。番組の半分は本人のものであり、**友人も「構わない」と明言済み**。
- フォロワーを増やしたい動機には、**ゆくゆく事業への流入も視野に入っている**。これは隠された動機ではなく本人が普通に述べたこと。
  - **Why**: 本人が避けたいのは宣伝臭さであって、事業との接続そのものではない。「私物化を避けたい」という以前の表現を、AI側が「事業との接続は一切NG」と過剰に読み、これをスタンス変更として指摘して訂正された（2026-08-03）。本人の立場は一貫している。
  - **How to apply**: リンクを貼る・言及するのは自由に提案してよい。避けるのは番組内での宣伝口調の固定CTA（「詳しくはnoteで！」等）。クリップ切り出しも**保留ではなく推奨**（ただし番組公式名義で、番組のための施策として）。今後この件を「スタンスが変わった」「友人の同意が必要」という枠組みで扱わない。

**note記事化の具体的ワークフロー案（2026-08-03検討）**
- Spotify for Creatorsには自動文字起こしが既にあるが、精度が低く話者区別もされていない
- この文字起こしは「記事を書くための正確な原文」としてではなく、「どの回で何を話したかを思い出すための索引」として使う。索引としてなら精度の低さは問題にならない
- 執筆フローは: 索引で該当エピソードを探す → 該当箇所を軽く聴き直して記憶を確認 → 自分個人の視点から記事を書く（AIに文字起こしをそのまま渡して記事化させない）→ 記事末尾に元エピソードへのリンクを置く
- **注意点**: 話者区別がない文字起こしのまま記事化すると、友人が言ったアイデアを自分の考えとして書いてしまう誤帰属リスクがある。これは「共同番組の私物化を避けたい」という本人のスタンスと真っ向から矛盾するため、聴き直しによる確認を省略しない

**規模と再文字起こしのコスト試算（2026-08-03）**
- 総エピソード数361件、平均10分/本 → 総尺約60時間
- AssemblyAI（文字起こし+話者分離込み）が最安、60時間で約$10〜14（2026-08時点の料金）。OpenAI Whisper APIは話者分離なしで約$22、Deepgramは話者分離込みで約$35
- 規模が小さいため、コスト面では「まとめて高精度で再文字起こしする」ことに対する障壁はほぼない
- 注意点: 話者分離は「Speaker A/B」がエピソード単位で振られるだけで、全エピソード横断で「本人/友人」の対応付けが自動で揃うわけではない（声紋照合の追加機能はあるが精度・コストが別途かかる）。361件分、話者ラベルの人名マッピングを確認する一手間が残る

**番組の実データ（2026-08-03に実際に調べて確認。以前は本人の自己申告ベースだった）**

- 第1回は2019-11-11（「7年」は概数、2026年11月で丸7年）。エピソード総数356本、最新は♯339。週1ペース。1本8〜11分

**フォロワー獲得の方針（2026-08-03検討）**
- ターゲットは**AもBも両方**（A=日本のクリスチャン層 / B=信者ではないが興味のある層）。両立させる分業は: **A→Appleカテゴリを「宗教・スピリチュアリティ>キリスト教」に変更**（日本ではガラガラで上位に入れる。この層はカテゴリを実際にbrowseする）、**B→YouTube展開＋短尺クリップ**（この層はカテゴリを見ない。検索とレコメンドで来る）
- **本人の第一感もYouTube**で、これは正しい。ポッドキャストアプリ内には発見エンジンがほぼ存在せず、YouTubeだけが本物のレコメンドを持つ。静止画+音声でよい
- **タイトルは「フックとして優秀だが検索性がない」**。タイトル自体は番組の資産なので変えず、概要欄に中身を書いて補う（再文字起こしの成果物が流用できる）
- **保留にした施策**: 他番組へのゲスト出演・相互紹介、JAPAN PODCAST AWARDS等への応募。本人が「敷居が高い」として現時点では見送り
- AI側の外した推測: エピソードタイトルが「内輪の言い回し」ではないかと data を見ずに指摘したが、実際は違った。この番組について語る前に実データを見ること
