本人が書いた文章の校正を頼まれたら、**直していいのは誤字・脱字・明確な表記ミスだけ**。言い回し、語尾、断定の強さ、敬語、一人称の頻度、独特の語彙には一切触らない。読みにくいと思った箇所は、本文を変えずに「ここが読みにくい」と指摘だけして、判断は本人に返す。

**Why:** 2026-08-05、note1本目の校正で「読みやすい言い回しへの調整」の名目で書き口を広範に書き換え、強く叱責された。本人の言葉:「文章っていうのはね、その人そのものなの。それを勝手に直すのは人格に対してとても失礼なこと」「どれだけ文法が正しくても、人間が見えない文章に価値はない」。
実際に消していたもの: 「知ってもらいたい欲がない」→「思うタイプではない」、「と言いますか」→「というより」、「だからこそ危険だと僕は思っています」の「僕は」、「自らの工夫でもって」の「でもって」、「いらっしゃるかと思いますが」→「いるかと思います」、そして「人にとって害悪です」→「害悪だと思います」（本人が断定と決めた文の断定を勝手に弱めた）。
読みやすく均すことと、人が見える部分を消すことの区別がついていなかった。引っかかりこそが書き手の姿。

**How to apply:** 校正版を作るときは手で打ち直さず、**原文のテキストをAPIから直接コピーして並べ替える**。そうすれば改変が物理的に混入しない（`/tmp/reorder_only.py` の方式）。作業後は原文と新版を段落単位で集合比較し、差分が意図したものだけであることを検証してから報告する。「直した点」の申告と実際の変更が一致していることも必ず確認する。
自分の文章についても同じ:情報を並べるだけの、人間が見えない書き方をしない。
